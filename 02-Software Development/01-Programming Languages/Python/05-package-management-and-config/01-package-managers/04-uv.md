# uv (The Future of Python Tooling)

## Summary
**uv** is an extremely fast Python package and project manager written in Rust. Released in 2024 by Astral (creators of Ruff), it aims to replace `pip`, `poetry`, `pip-tools`, and `virtualenv` with a single, high-performance binary.

## Detailed Explanation

### Why uv?
*   **Speed**: It is 10-100x faster than pip/poetry due to Rust implementation and aggressive caching.
*   **Unified Tool**: It manages Python versions (`uv python install`), virtual environments (`uv venv`), and dependencies (`uv add`).
*   **Compatibility**: It uses standard `pyproject.toml` (PEP 621) but generates a universal `uv.lock` file.

### Key Commands
*   **Init**: `uv init` (Creates pyproject.toml)
*   **Add**: `uv add requests` (Installs and adds to dependencies)
*   **Run**: `uv run script.py` (Runs script in ephemeral env with deps)
*   **Sync**: `uv sync` (Ensures env matches lockfile)

### Workspaces
uv supports **Workspaces**, allowing you to manage multiple packages in a single repository (monorepo style) sharing a lock file.

```toml
# pyproject.toml
[tool.uv.workspace]
members = ["packages/*"]
```

## Interview Questions

**Q: How does `uv` achieve such high performance?**
**A:** It is written in Rust, uses a global content-addressable cache (deduplication), and utilizes parallel downloads/installs. It also avoids some overhead of Python's runtime during resolution.

**Q: Does `uv` use `requirements.txt`?**
**A:** It can read/write them for compatibility, but its native workflow uses `pyproject.toml` and `uv.lock`.

**Q: Can `uv` install Python itself?**
**A:** Yes. `uv python install 3.12` downloads and manages Python toolchains, decoupling your project from the system Python.
