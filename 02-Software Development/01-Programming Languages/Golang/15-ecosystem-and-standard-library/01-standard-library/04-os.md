# OS Package

## Summary
The `os` package provides a platform-independent interface to operating system functionality. While it handles file I/O (covered separately), it is also the primary tool for interacting with the **environment**, **processes**, **signals**, and **file system permissions**. It aims to be uniform across Unix, Windows, and macOS.

## Detailed Explanation

### 1. Environment Variables
Reading and writing environment variables is essential for configuration (12-factor apps).
```go
package main
import (
    "fmt"
    "os"
)

func main() {
    // Set a variable
    os.Setenv("APP_PORT", "8080")

    // Get a variable
    port := os.Getenv("APP_PORT")
    
    // Check if exists (distinguish empty vs missing)
    val, exists := os.LookupEnv("MISSING_VAR")
    if !exists {
        fmt.Println("Variable not set")
    }
}
```

### 2. Command Line Arguments
*   `os.Args`: A slice of strings representing the command executed. `os.Args[0]` is the program name.

### 3. Exiting
*   `os.Exit(code)`: Exits the program immediately with the given status code (0 for success, non-zero for error).
    *   **Warning**: Deferred functions are **NOT** run when `os.Exit` is called.

### 4. Process Signals (Graceful Shutdown)
Handling signals (like `SIGINT` / Ctrl+C) is critical for servers to finish requests before shutting down.
```go
c := make(chan os.Signal, 1)
// Notify the channel on Interrupt (Ctrl+C) or SIGTERM
signal.Notify(c, os.Interrupt, syscall.SIGTERM)

// Block until signal received
<-c 
fmt.Println("Shutting down...")
```

### 5. Executing External Commands
Use `os/exec` (sub-package) to run shell commands.
```go
cmd := exec.Command("grep", "hello", "file.txt")
output, err := cmd.CombinedOutput()
```

### 6. File System Permissions
*   `os.Chmod(name, mode)`: Change file mode bits (e.g., `0777`).
*   `os.Chown(name, uid, gid)`: Change owner/group.
*   `os.Mkdir(name, perm)`: Create directory.
*   `os.Stat(name)`: Get file info (size, mod time, checking existence).
    ```go
    if _, err := os.Stat("file.txt"); os.IsNotExist(err) {
        fmt.Println("File does not exist")
    }
    ```

## Interview Questions

**Q: What happens to `defer` statements when you call `os.Exit(1)`?**
**A:** They are **not** executed. The program terminates immediately. If you need to run cleanup code (like closing DB connections or flushing logs), you should return from `main()` instead of calling `os.Exit()`, or handle the cleanup manually before the exit call.

**Q: How do you robustly check if a file exists in Go?**
**A:** You use `os.Stat` and check the error.
```go
if _, err := os.Stat(path); err == nil {
    // exists
} else if os.IsNotExist(err) {
    // does not exist
} else {
    // other error (permission, etc.)
}
```

**Q: How does `os.ExpandEnv` work?**
**A:** It replaces `${var}` or `$var` in a string with the values of the current environment variables. This is useful for parsing configuration files that support variable substitution.
