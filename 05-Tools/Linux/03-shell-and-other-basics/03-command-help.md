## Summary
In Linux, obtaining help for commands is a fundamental skill. The system provides several built-in documentation formats, ranging from concise usage summaries to comprehensive, hyperlinked manuals. Understanding how to use `man`, `--help`, `info`, and `whatis` ensures that users can effectively use tools and troubleshoot issues without relying on external resources.

## Detailed Explanation

### 1. Manual Pages (`man`)
The `man` command is the standard interface for system reference manuals. It displays documentation for commands, system calls, library functions, and configuration files.

*   **Usage**: `man <command>` (e.g., `man ls`).
*   **Sections**: The manual is divided into sections to distinguish between commands and other system elements:
    1.  **User Commands** (e.g., `ls`, `grep`)
    2.  **System Calls** (e.g., `open`, `read`)
    3.  **Library Functions** (e.g., `printf` in C)
    4.  **Special Files** (e.g., `/dev/null`)
    5.  **File Formats** (e.g., `/etc/passwd`)
    6.  **Games**
    7.  **Miscellaneous**
    8.  **System Administration** (e.g., `ip`, `mount`)
*   **Navigation**: `man` uses a pager (usually `less`).
    *   `Space`: Next page
    *   `b`: Previous page
    *   `/pattern`: Search for a pattern
    *   `q`: Quit

### 2. The `--help` Flag
Most GNU/Linux commands support a `--help` (or sometimes `-h`) flag. This provides a brief summary of the command's usage, available flags, and parameters. Unlike `man`, this output is generated by the program itself.

```bash
ls --help
```

### 3. Info Pages (`info`)
The `info` system is a more modern, menu-driven, and hyperlinked documentation format primarily used by GNU tools. It provides a more structured "book-like" experience compared to the flat text of `man`.

*   **Usage**: `info <command>`
*   **Navigation**: Uses `n` for next node, `p` for previous node, and `u` to go up one level.

### 4. `whatis` and `apropos`
*   **`whatis`**: Searches the `whatis` database for complete words and displays a one-line description.
    *   Example: `whatis ls` -> `ls (1) - list directory contents`.
*   **`apropos`**: Searches the manual page descriptions for a keyword. Useful when you don't know the exact command name.
    *   Example: `apropos "network configuration"`

### 5. `help` (Shell Builtins)
Commands built directly into the shell (like `cd`, `exit`, `history`) don't have separate manual pages. For these, use the shell's internal `help` command.

```bash
help cd
```

### Go Application: Implementing Command Help
In Go, the `flag` package automatically handles the `-h` and `--help` flags. When a user provides an undefined flag or asks for help, the package prints a default usage message.

```go
package main

import (
	"flag"
	"fmt"
	"os"
)

func main() {
	// Define flags
	name := flag.String("name", "World", "The name to greet")
	age := flag.Int("age", 0, "The age of the person")

	// Customizing the Usage message
	flag.Usage = func() {
		fmt.Fprintf(os.Stderr, "Usage of %s:\n", os.Args[0])
		fmt.Println("This tool greets people and demonstrates help flags.")
		flag.PrintDefaults()
	}

	flag.Parse()

	fmt.Printf("Hello, %s! You are %d years old.\n", *name, *age)
}
```

Running this program with `--help` will output:
```text
Usage of ./main:
This tool greets people and demonstrates help flags.
  -age int
    	The age of the person
  -name string
    	The name to greet (default "World")
```

## Interview Questions

**Q: What is the difference between `man` and `info`?**
**A:** `man` pages are traditional, flat text reference manuals focused on a single topic. `info` pages are hyperlinked, menu-based documents that allow for easier navigation between related topics, often providing more comprehensive "tutorial-style" documentation for GNU tools.

**Q: How do you search for a command if you only know its function but not its name?**
**A:** Use the `apropos` command or `man -k` followed by a keyword. This searches the short descriptions in the manual page headers for matches.

**Q: What do the numbers in parentheses like `chmod(1)` or `passwd(5)` represent?**
**A:** They represent the manual section. `(1)` refers to general user commands, while `(5)` refers to file formats and conventions (like the structure of the `/etc/passwd` file).

**Q: Why does `man cd` sometimes fail or show a different message than expected?**
**A:** `cd` is a shell builtin, not a standalone executable. While some systems provide a `man` entry for builtins, the primary way to get help for them is using the shell's `help` command (e.g., `help cd`).
