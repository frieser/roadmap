# cd (Change Directory)

## Summary

The `cd` command changes the current working directory. It's a shell builtin (not an external program) that modifies the shell's environment. Understanding special directories like `.`, `..`, `~`, and `-` is essential for efficient navigation.

## Detailed Explanation

### Basic Navigation

```bash
# Change to directory
cd /var/log
cd projects

# Home directory
cd          # Goes to $HOME
cd ~        # Same as above
cd ~user    # Go to another user's home

# Parent directory
cd ..
cd ../..    # Two levels up

# Previous directory
cd -        # Toggle between last two directories
# Equivalent to: cd "$OLDPWD"
```

### Special Directories

| Symbol | Meaning |
|--------|---------|
| `.` | Current directory |
| `..` | Parent directory |
| `~` | Home directory ($HOME) |
| `-` | Previous directory ($OLDPWD) |
| `/` | Root directory |

### Directory Stack (pushd/popd)

```bash
# Push directory to stack and change to it
pushd /var/log
# /var/log ~

# Push another
pushd /tmp
# /tmp /var/log ~

# View stack
dirs -v
# 0  /tmp
# 1  /var/log
# 2  ~

# Pop and return
popd
# /var/log ~

# Rotate stack
pushd +1    # Move second to top
```

### cd in Scripts

```bash
#!/bin/bash

# cd in scripts affects only the script
cd /tmp
# Parent shell's directory unchanged

# Handle cd failure
cd "$DIR" || exit 1

# cd in subshell doesn't affect parent
(cd /tmp && do_something)
pwd   # Still in original directory
```

### Shell Options for cd

```bash
# Auto-correct minor typos
shopt -s cdspell
cd /usr/locla   # Corrects to /usr/local

# cd to directory by just typing name
shopt -s autocd
/var/log        # Same as: cd /var/log

# CDPATH - search path for cd
export CDPATH=".:~:~/projects"
cd myapp        # Finds ~/projects/myapp
```

## Interview Questions

**Q: What is the difference between `cd` and `pushd`?**
**A:** `cd` simply changes directory. `pushd` saves the current directory on a stack before changing, allowing you to return with `popd`. Useful for returning after temporary navigation.

**Q: Why does `cd` in a script not affect the parent shell?**
**A:** Scripts run in a subshell. Each process has its own working directory. Changes in a child process don't affect the parent. To affect the current shell, use `source script.sh` or `. script.sh`.
