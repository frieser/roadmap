# ls (List Directory Contents)

## Summary

The `ls` command lists files and directories. It's one of the most frequently used commands, with many options for sorting, filtering, and displaying file information. Understanding `ls` output and options is fundamental for filesystem navigation.

## Detailed Explanation

### Basic Usage

```bash
# List current directory
ls

# List specific directory
ls /var/log

# List multiple locations
ls /etc /var
```

### Common Options

```bash
# -l: Long format (detailed)
ls -l
# -rw-r--r-- 1 user group 4096 Jan 15 12:00 file.txt
# │          │ │    │     │    │           └── name
# │          │ │    │     │    └── modification date
# │          │ │    │     └── size in bytes
# │          │ │    └── group
# │          │ └── owner
# │          └── link count
# └── permissions

# -a: All files (including hidden)
ls -a

# -A: Almost all (exclude . and ..)
ls -A

# -h: Human-readable sizes (with -l)
ls -lh    # Shows 4.0K instead of 4096

# -R: Recursive
ls -R
```

### Sorting Options

```bash
# -t: Sort by modification time (newest first)
ls -lt

# -S: Sort by size (largest first)
ls -lS

# -r: Reverse sort order
ls -ltr    # Oldest first

# -X: Sort by extension
ls -lX
```

### Filtering and Display

```bash
# Show only directories
ls -d */

# -1: One file per line
ls -1

# Show file types
ls -F
# / = directory, * = executable, @ = symlink

# --color: Colorize output (usually default)
ls --color=auto
```

### Understanding Permissions

```bash
ls -l file.txt
# -rw-r--r--
# │└┬┘└┬┘└┬┘
# │ │  │  └── others: read
# │ │  └── group: read
# │ └── owner: read, write
# └── type: - = file, d = directory, l = link

# First character types:
# -  regular file
# d  directory
# l  symbolic link
# c  character device
# b  block device
# p  named pipe
# s  socket
```

### Common Aliases

```bash
# Typical .bashrc aliases
alias ls='ls --color=auto'
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
```

## Interview Questions

**Q: What does `ls -la` show?**
**A:** Long format (`-l`) with all files including hidden (`-a`). Shows permissions, link count, owner, group, size, date, and filename for every file.

**Q: How do you sort files by modification time?**
**A:** Use `ls -lt` for newest first, or `ls -ltr` for oldest first (reverse). Add `-h` for human-readable sizes.
