# Vi

## Summary

**Vi** (Visual editor) is the original Unix text editor, created by Bill Joy in 1976. Vi is the predecessor to Vim (Vi IMproved) and is universally available on all Unix-like systems, including Linux, macOS, and BSD. Understanding basic vi is essential for emergency system administration when modern editors may not be available.

## Detailed Explanation

### Why Learn Vi?

| Reason | Description |
|---------|-------------|
| **Universal** | Available on ALL Unix/Linux systems |
| **Lightweight** | No dependencies, minimal resource usage |
| **Recovery Mode** | Often the only editor in single-user mode |
| **Network** | Works over slow connections (no GUI overhead) |
| **Foundation** | Skills transfer to Vim and enhanced vi-clones |

### Vi vs Vim vs Other Editors

| Feature | Vi | Vim | Nano | Emacs |
|---------|-----|------|-------|--------|
| **Availability** | Universal | Very High | High | High |
| **Syntax Highlighting** | No | Yes | Basic | Yes |
| **Undo Levels** | Limited (1) | Unlimited | Unlimited |
| **Plugins** | No | Yes | Yes |
| **Modes** | Yes (basic) | Yes (enhanced) | No |
| **Learning Curve** | Medium | Hard | Easy | Very Hard |
| **Mouse Support** | No | Possible | Yes |

### Vi Modes

| Mode | Purpose | Enter | Exit |
|-------|---------|--------|-------|
| **Command Mode** | Navigation, editing commands | Default/`Esc` | N/A |
| **Insert Mode** | Typing text | `i`, `a`, `o`, `O` | `Esc` |
| **Last Line Mode** | Save, quit, search, replace | `:` | `Enter`/`Esc` |

### Basic Vi Commands

#### Entering Vi and Getting Help

```bash
vi                    # Open new file
vi filename.txt        # Open specific file
vi +10 filename.txt   # Open at line 10
vi file1 file2        # Open multiple files

# Built-in help (limited in original vi)
vi :help              # Vim only, not in traditional vi
```

#### Navigation (Command Mode)

| Command | Action |
|---------|--------|
| `h`, `j`, `k`, `l` | Left, down, up, right |
| `0`, `$` | Start/end of line |
| `w`, `b` | Next/previous word |
| `G` | Go to last line |
| `1G` | Go to line 1 |
| `Ctrl+f` | Forward one page |
| `Ctrl+b` | Backward one page |
| `Ctrl+d` | Forward half page |
| `Ctrl+u` | Backward half page |

#### Insert Mode

| Command | Action |
|---------|--------|
| `i` | Insert before cursor |
| `I` | Insert at beginning of line |
| `a` | Append after cursor |
| `A` | Append at end of line |
| `o` | Open new line below |
| `O` | Open new line above |
| `Esc` | Return to command mode |

#### Editing

| Command | Action |
|---------|--------|
| `x` | Delete character |
| `X` | Delete character before cursor |
| `dw` | Delete word |
| `dd` | Delete line |
| `dG` | Delete to end of file |
| `d0` | Delete to beginning of line |
| `d$` | Delete to end of line |
| `r` | Replace single character |
| `R` | Replace mode |
| `u` | Undo (may be limited) |
| `U` | Undo all changes on line |

#### Copy and Paste

| Command | Action |
|---------|--------|
| `yy` | Yank (copy) line |
| `p` | Paste after cursor |
| `P` | Paste before cursor |
| `yw` | Yank word |
| `y$` | Yank to end of line |
| `y0` | Yank to beginning of line |

#### Last Line Mode Commands

| Command | Action |
|---------|--------|
| `:w` | Write (save) file |
| `:q` | Quit |
| `:wq` | Write and quit |
| `:q!` | Quit without saving |
| `:x` | Write and quit (same as wq) |
| `:e filename` | Edit another file |
| `:n` | Next file (if multiple files opened) |
| `:p` | Previous file |

### Search and Replace

```vi
" Search forward
/pattern
n              " Next occurrence
N              " Previous occurrence

" Search backward
?pattern
n              " Previous occurrence
N              " Next occurrence

" Replace on current line
:s/old/new/     " First occurrence
:s/old/new/g    " All on line

" Replace in entire file
:%s/old/new/     " First occurrence per line
:%s/old/new/g    " All occurrences

" Replace with confirmation
:%s/old/new/gc   " Ask before each replacement
```

### File Operations

```vi
" Opening multiple files
vi file1.txt file2.txt file3.txt

" Switching between files
:n              " Next file
:N              " Previous file

" Saving under different name
:w newfile.txt

" Reading another file into buffer
:r another.txt

" Inserting output of command
:r !ls -la
```

### Vi vs Traditional Vi vs Enhanced Vi

```bash
# Traditional vi (original BSD/SVR4 vi)
vi              " Original vi on many systems

# Enhanced vi clones (vim, nvi, elvis)
vim             " Vi IMproved (most common)
nvi             " New vi (BSD)
elvis           " Enhanced vi clone

# Check which vi you have
vi --version        # Usually shows vim or nvi
which vi            # Shows symlink target
```

### Vi Limitations (What Vim Has)

```bash
" Traditional vi lacks:
" - Syntax highlighting
" - Multiple undo (usually 1 level)
" - Multiple windows/splits
" - Plugins
" - Visual block mode
" - Extensive help system
" - Macro recording
" - Mouse support
" - Easy configuration

" That's why most systems provide vim as /usr/bin/vi
```

### Practical Vi Scenarios

#### Emergency System Recovery

```bash
" System boots to single-user mode
# Only basic tools available, vi works

# Edit fstab to fix boot issue
vi /etc/fstab

# Edit passwd to fix user
vi /etc/passwd

# Edit network config
vi /etc/network/interfaces
```

#### Remote Server Over Slow Connection

```bash
" Minimal bandwidth, need efficient editor

# Edit config file
vi ~/.ssh/config

# Make changes and save
:wq
```

#### Minimal System/Docker Container

```bash
" Alpine Linux or minimal container
# No vim installed, only vi

apk add vi          # Install vi
vi app.conf          # Edit config
```

### Common Vi Workflows

#### Quick Edit

```bash
" 1. Open file
vi config.txt

" 2. Move to line (e.g., line 50)
:50

" 3. Enter insert mode
i

" 4. Make changes
Esc

" 5. Save and exit
:wq
```

#### Find and Replace

```bash
" 1. Search for pattern
/TODO

" 2. Go through matches
n, n, n

" 3. Replace all occurrences
:%s/TODO/DONE/g

" 4. Save and exit
:wq
```

#### Delete Multiple Lines

```bash
" 1. Go to start line
:10

" 2. Delete 20 lines (lines 10-29)
20dd

" 3. Save
:w
```

### Vi Configuration

```bash
# Traditional vi has limited configuration
# .exrc or .vimrc (vim)

" ~/.exrc
set showmode         " Show current mode
set autoindent       " Auto indentation
set number           " Show line numbers (may not work in all vi)

" Note: Many settings only work in vim, not traditional vi
```

## Interview Questions

**Q: What is the difference between vi and vim?**
**A:** Vim (Vi IMproved) is an enhanced version of vi with syntax highlighting, multiple undo, visual modes, macros, and plugins. Vi is the original editor with basic features. Most Linux systems provide vim as `/usr/bin/vi` for backward compatibility.

**Q: Why learn vi when vim and nano are available?**
**A:** Vi is available on every Unix system, including recovery mode, minimal containers, and legacy systems where vim or nano may not be installed. Understanding basic vi is essential for emergency administration when nothing else works.

**Q: What are the basic modes in vi?**
**A:** Command mode (navigation and editing commands, default), Insert mode (typing text - enter with `i`, `a`, `o`), and Last Line mode (save, quit, replace - enter with `:`). Press `Esc` to return to command mode from insert mode.

**Q: How do you save and exit in vi?**
**A:** Press `Esc` to ensure command mode, then type `:w` to write (save) and `:q` to quit. Combined: `:wq` saves and quits. Force quit without saving: `:q!`.

**Q: What is the difference between `:wq` and `:x` in vi?**
**A:** `:wq` writes file and quits. `:x` writes file only if changes were made, then quits. For most practical purposes, they behave identically. Traditional vi may not support `:x` (use `:wq` instead).
