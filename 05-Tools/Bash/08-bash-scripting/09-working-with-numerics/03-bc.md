## Summary
`bc` (Basic Calculator) is an arbitrary-precision calculator language. It is the standard tool in shell scripting for performing **floating-point arithmetic**, advanced math functions (sine, cosine, log), and base conversions, which Bash cannot handle natively.

## Detailed Explanation

### Basic Usage
Pipe expression to `bc`.
`echo "10 / 3" | bc` -> `3` (Default is integer math).

### Floating Point (`-l`)
To enable decimals, use the `-l` (math library) flag or set `scale`.
`echo "10 / 3" | bc -l` -> `3.33333333333333333333`

### Scale
`scale` determines the number of decimal places.
`echo "scale=2; 10 / 3" | bc` -> `3.33`

## Go-Specific Context/Examples

Go uses the `math` package for standard float64 operations and `math/big` for arbitrary-precision arithmetic (like `bc`).

### Analogy
**Bash**: `echo "scale=50; 22/7" | bc`
**Go**:
```go
import "math/big"
// use big.NewFloat to handle high precision
```

## Interview Questions

**Q: Why does `echo "1.5 + 1.5" | bc` print `3.0` but `$((1.5+1.5))` fail?**
**A:** Bash's built-in arithmetic `$((...))` is strictly integer-based. `bc` is a separate calculator utility designed to handle floats.

**Q: How do you use `bc` for boolean logic?**
**A:** `bc` returns 1 for true and 0 for false.
`echo "5 > 3" | bc` -> `1`.
You can use this in `if` statements:
`if (( $(echo "5.5 > 3.2" | bc -l) )); then echo "Yes"; fi`

**Q: How do you convert Hex to Decimal?**
**A:** `echo "ibase=16; FF" | bc`. (Input Base = 16).
