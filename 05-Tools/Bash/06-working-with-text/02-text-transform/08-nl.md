## Summary
`nl` (Number Lines) is a specialized utility to output a file with line numbers added. While `cat -n` also numbers lines, `nl` offers more sophisticated control, such as numbering only non-blank lines (default) or formatting the number column.

## Detailed Explanation

### Basic Usage
*   `nl file.txt`: Numbers non-empty lines.
*   `cat -n file.txt`: Numbers **all** lines (including empty ones).

### Formatting Options
*   **`-b a`**: Number **a**ll lines (same as `cat -n`).
*   **`-b t`**: Number only non-empty lines (**t**ext) - Default.
*   **`-w 4`**: Width of number column (e.g., 4 digits).
*   **`-s ': '`**: Separator after number (default is TAB).

### Logical Pages
`nl` can reset numbering for logical pages if the file contains delimiter lines (like `\:\:\:`), though this feature is rarely used in modern scripting.

## Go-Specific Context/Examples

Adding line numbers in Go is a common task when building CLI tools (like `bat` clones) or logging.

### Example: Numbering Output in Go
```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	scanner := bufio.NewScanner(os.Stdin)
	lineNum := 1
	for scanner.Scan() {
		text := scanner.Text()
		if text != "" {
			fmt.Printf("%6d\t%s\n", lineNum, text)
			lineNum++
		} else {
			fmt.Println() // Print empty line without number
		}
	}
}
```

## Interview Questions

**Q: When would you use `nl` over `cat -n`?**
**A:** When you want to skip numbering empty lines to make the output cleaner or to count only the actual lines of code/text.

**Q: How do you format the line numbers to be zero-padded (001, 002)?**
**A:** Use `nl -n rz` (Right justified, Zero padded).
`nl -n rz -w 3 file.txt` -> `001 line one`.
