## Summary
`tr` (translate) is a lightweight stream editor used for translating or deleting characters. Unlike `sed` or `awk`, `tr` only works on **single characters**, making it extremely fast for simple replacements like upper-casing text or removing whitespace.

## Detailed Explanation

### Common Operations
1.  **Translate (Replace)**:
    *   `tr 'a-z' 'A-Z'`: Convert Lowercase to Uppercase.
    *   `tr ':' ','`: Replace colons with commas.
2.  **Delete**:
    *   `tr -d '0-9'`: Delete all digits.
    *   `tr -d '\r'`: Delete DOS carriage returns (fixing CRLF issues).
3.  **Squeeze**:
    *   `tr -s ' '`: Replace sequences of repeated characters with a single instance (e.g., convert multiple spaces to one space).

### Syntax
`tr [options] SET1 [SET2]`
*   Input comes from **Stdin** only (it does not accept filenames as arguments).
*   `cat file.txt | tr 'a' 'b'`

## Go-Specific Context/Examples

In Go, the `strings` package handles these operations efficiently.

### Analogy
*   **Translate**: `tr 'a' 'b'` ≈ `strings.ReplaceAll(s, "a", "b")` or `strings.Map`.
*   **Upper Case**: `tr 'a-z' 'A-Z'` ≈ `strings.ToUpper(s)`.
*   **Delete**: `tr -d 'a'` ≈ `strings.ReplaceAll(s, "a", "")`.

### Example: strings.Map
```go
// Remove non-ascii (Conceptual)
clean := strings.Map(func(r rune) rune {
    if r > 127 {
        return -1 // Delete
    }
    return r
}, input)
```

## Interview Questions

**Q: What is the difference between `tr` and `sed`?**
**A:** `tr` operates on **characters** (1-to-1 mapping or deletion). `sed` operates on **strings** and supports full Regular Expressions. You cannot use `tr` to replace "apple" with "orange", but you can use it to replace "a" with "o".

**Q: How do you remove all newlines from a file using `tr`?**
**A:** `tr -d '\n' < file.txt`. This creates one giant long line.

**Q: Why doesn't `tr file.txt` work?**
**A:** `tr` strictly reads from Standard Input (stdin). It does not handle file I/O. You must use redirection (`<`) or piping (`cat | tr`).
