# Project Planning

## Summary
GitHub Projects is a project management tool built directly into GitHub. It allows you to track issues, pull requests, and notes in a spreadsheet-like or board-like interface.

## Detailed Explanation

### Features
*   **Issues Integration**: Directly link to real issues.
*   **Custom Fields**: Add metadata like "Priority", "Size", "Due Date".
*   **Views**: Switch between Table, Board, and Roadmap.

### Go-specific Context
Large Go projects (like Kubernetes) use complex Project boards to manage the thousands of issues and PRs across multiple SIGs (Special Interest Groups).

## Interview Questions
**Q: Is GitHub Projects distinct from the Repository?**
**A:** Yes, a Project can span multiple repositories (Organization-level Project) or be tied to a single user.
