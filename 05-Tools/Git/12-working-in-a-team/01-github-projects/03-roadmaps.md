# Roadmaps

## Summary
The Roadmap view in GitHub Projects offers a Gantt-chart style visualization. It plots items on a timeline based on their "Start Date" and "Target Date" fields.

## Detailed Explanation

### Use Cases
*   **Release Planning**: Visualize when v1.0, v1.1 are expected.
*   **Dependency Tracking**: See which tasks block others.

### Configuration
You need to add custom Date fields to your project to enable the Roadmap view.

## Interview Questions
**Q: Is the Roadmap view available on personal free accounts?**
**A:** Yes, the new GitHub Projects (V2) is available for free, though some enterprise features might be gated.
