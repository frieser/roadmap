# Kanban Boards

## Summary
A Kanban board is a visualization tool for workflow. GitHub Projects provides a Kanban view with columns typically representing states like "Todo", "In Progress", "In Review", and "Done".

## Detailed Explanation

### Workflow
1.  **Backlog**: Pool of all issues.
2.  **Todo**: Issues selected for the current sprint.
3.  **In Progress**: Currently being worked on.
4.  **Done**: PR merged and deployed.

### Drag and Drop
You can drag cards (Issues) between columns to update their status field automatically.

## Interview Questions
**Q: Can you automate column movements?**
**A:** Yes, GitHub Projects has built-in workflows to move items when specific events happen (e.g., "Move to Done when PR is merged").
