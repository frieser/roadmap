# GitHub Sponsors

## Summary
GitHub Sponsors allows the community to financially support the people and organizations who build the open source software they rely on.

## Detailed Explanation

### How it works
*   **Profile**: Developers create a profile explaining their work.
*   **Tiers**: Users can subscribe monthly ($5, $10, $100) or one-time.
*   **Matching**: GitHub sometimes matches contributions during special periods.

### Go-specific Context
Many prominent Go library maintainers (like the creators of Gin, Echo, or Viper) rely on Sponsors to fund the time they spend maintaining these critical ecosystem tools.

## Interview Questions
**Q: Does GitHub take a cut?**
**A:** GitHub currently waives all fees for Sponsors, so 100% goes to the developer (minus payment processing fees in some cases).
