# GitHub Marketplace

## Summary
The Marketplace is the central store for finding tools to extend your workflow. It hosts **GitHub Actions** and **GitHub Apps**.

## Detailed Explanation

### Categories
*   **Actions**: Building blocks for CI/CD (e.g., "Upload to S3").
*   **Apps**: Integrations (e.g., "Slack", "Jira", "Sentry").

### Verification
Look for the "Verified Creator" badge (blue checkmark) to ensure the action/app comes from a trusted vendor.

## Interview Questions
**Q: Can you sell actions on the Marketplace?**
**A:** Yes, you can list paid Apps (but Actions are generally free/open source).
