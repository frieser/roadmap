# GitHub Education

## Summary
GitHub Education offers benefits to schools, teachers, and students. It includes the Student Developer Pack, Classroom, and Campus Experts program.

## Detailed Explanation

### Campus Experts
A training program for student leaders to build technical communities at their schools.

### Swag
GitHub often provides stickers and resources for hackathons organized by students.

## Interview Questions
**Q: Is GitHub Pro free for students?**
**A:** Yes, verifying your student status gives you GitHub Pro for free while you are a student.
