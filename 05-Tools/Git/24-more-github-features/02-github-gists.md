# GitHub Gists

## Summary
Gists are a way to share code snippets or single files instantly. They are essentially mini-repositories.

## Detailed Explanation

### Types
*   **Public**: Searchable, anyone can see.
*   **Secret**: Not searchable, but accessible if you have the link.

### Features
*   **Versioning**: Gists are Git repositories. You can clone them and commit changes.
*   **Embed**: You can embed a Gist in a blog post using a simple JS script tag.

### Go-specific Context
The Go Playground (`go.dev/play`) allows you to save snippets, but Gists are better for persistent, versioned sharing of small scripts or Makefiles.

## Interview Questions
**Q: Can a Gist have multiple files?**
**A:** Yes.

**Q: Can you convert a Gist to a full repo?**
**A:** Not automatically, but since it's a git repo, you can push it to a new GitHub repository.
