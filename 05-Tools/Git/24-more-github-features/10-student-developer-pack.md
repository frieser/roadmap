# Student Developer Pack

## Summary
A bundle of free access to best-in-class developer tools for students.

## Detailed Explanation

### Contents (Examples)
*   **GitHub**: Free Pro.
*   **DigitalOcean**: Cloud credit.
*   **Namecheap**: Free domain name (.me).
*   **JetBrains**: Free IDEs (GoLand, IntelliJ).
*   **Heroku**: Credits.

### Eligibility
Must be enrolled in a degree-granting program and have a school email (`.edu`) or student ID.

## Interview Questions
**Q: Can bootcamp students apply?**
**A:** Yes, many approved bootcamps are eligible.
