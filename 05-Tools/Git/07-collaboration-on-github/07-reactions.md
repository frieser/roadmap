# Reactions

## Summary
Reactions allows users to respond to a comment with an emoji (👍, 👎, 😄, 🎉, 😕, ❤️, 🚀, 👀) instead of posting a "Me too" or "+1" comment. This reduces noise and keeps the conversation thread clean.

## Detailed Explanation

### Benefits
*   **Reduces Notification Spam**: Posting "+1" sends an email to everyone watching the thread. Clicking 👍 does not.
*   **Sorting**: You can sort comments by reaction count (e.g., "Sort by Best Match" or most +1s).

### Usage
Click the smiley face icon in the top right of any comment.

### Go-specific Context
In Go language proposals (issues), the Go team explicitly asks users to use reactions (👍/👎) to signal sentiment towards a proposed language change, rather than flooding the issue with "I agree" comments. This helps them gauge community consensus quantitatively.

## Interview Questions
**Q: Can you react to your own comment?**
**A:** Yes.

**Q: Do reactions count as activity for keeping an issue open?**
**A:** Generally no, automated "stale bots" usually look for new comments or commits, not reactions.
