## Summary
**NP (Nondeterministic Polynomial Time)** is the class of decision problems where a "yes" instance can be **verified** in polynomial time given a certificate (proof). While finding the solution might verify exponential time, checking a proposed solution is efficient. All problems in P are also in NP.

## Detailed Explanation
**NP** stands for **Nondeterministic Polynomial time**. It does *not* stand for "Non-Polynomial". A problem is in NP if a nondeterministic Turing machine could solve it in polynomial time. Equivalently, and more practically, it is the set of problems where a solution can be *verified* quickly.

### Verification vs. Solving
*   **Solving**: Finding the answer from scratch. (Might be hard)
*   **Verifying**: Taking a proposed answer and checking if it is correct. (Must be easy for NP)

### Example: Sudoku
*   **Solving** a generic $n \times n$ Sudoku board is hard (NP-Complete).
*   **Verifying** a completed board is easy (Polynomial). You just check if every row, column, and box contains unique numbers.

### Go Application
In Go, we often write "verifiers" for complex problems in test suites.

```go
package main

import "fmt"

// Subset Sum Problem (Verifier)
// Problem: Is there a subset of 'set' that sums to 'target'?
// This verifier checks if a SPECIFIC subset sums to the target.
// Time Complexity: O(k) where k is subset size (Polynomial)

func VerifySubsetSum(set []int, subsetIndices []int, target int) bool {
	sum := 0
	for _, idx := range subsetIndices {
		if idx < 0 || idx >= len(set) {
			return false // Invalid index
		}
		sum += set[idx]
	}
	return sum == target
}

func main() {
	set := []int{3, 34, 4, 12, 5, 2}
	target := 9
	
	// Proposed solution: indices 2 (value 4) and 4 (value 5)
	// 4 + 5 = 9
	indices := []int{2, 4}
	
	if VerifySubsetSum(set, indices, target) {
		fmt.Println("Solution Verified: Valid Subset")
	} else {
		fmt.Println("Solution Invalid")
	}
}
```

## Interview Questions
**Q: Does NP mean "Non-Polynomial"?**
A: No, it stands for "Nondeterministic Polynomial". It refers to the time verifiable by a deterministic machine or solvable by a nondeterministic one.

**Q: What is the relationship between P and NP?**
A: $P \subseteq NP$. Any problem that can be solved in polynomial time can also be verified in polynomial time. The big question is whether $NP \subseteq P$ (i.e., is P = NP?).

**Q: Why is Sudoku considered an NP problem?**
A: Because if someone gives you a completed grid, you can check its validity in polynomial time ($O(n^2)$), satisfying the definition of NP.
