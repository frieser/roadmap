## Summary
**P (Polynomial Time)** is the complexity class containing decision problems that can be **solved** by a deterministic Turing machine in polynomial time. These are problems that are considered "efficiently solvable" or "tractable" for practical input sizes. Common examples include sorting, searching, and basic arithmetic operations.

## Detailed Explanation
The class **P** stands for **Polynomial Time**. It represents the set of problems for which an algorithm exists that can solve the problem in time $O(n^k)$ for some constant $k$, where $n$ is the size of the input.

### Key Characteristics
1.  **Tractability**: Problems in P are generally considered solvable in practice.
2.  **Deterministic**: The solution is found by a deterministic computer (like standard CPUs) without guessing.
3.  **Closure**: P is closed under addition, multiplication, and composition.

### Why It Matters
In software engineering, determining if a problem is in P is the first step in algorithm design. If a problem is in P, we look for the most efficient polynomial algorithm (e.g., $O(n \log n)$ vs $O(n^2)$). If it is likely not in P (e.g., NP-Hard), we shift strategies to approximations or heuristics.

### Go Application
In Go, any function that runs in polynomial time relative to its input falls into this category. Most standard library functions are in P.

```go
package main

import (
	"fmt"
	"sort"
)

// Example of a P-class problem: Sorting
// Complexity: O(n log n) - Polynomial
func main() {
	numbers := []int{5, 2, 9, 1, 5, 6}
	
	// Check if a number exists (Linear Search: O(n))
	exists := contains(numbers, 9)
	fmt.Printf("Contains 9? %v\n", exists)

	// Sorting the slice
	sort.Ints(numbers)
	fmt.Println("Sorted:", numbers)
}

// contains checks for an element in a slice
// Time Complexity: O(n) - which is Polynomial (n^1)
func contains(arr []int, target int) bool {
	for _, v := range arr {
		if v == target {
			return true
		}
	}
	return false
}
```

## Interview Questions
**Q: What does the 'P' in P-Class stand for?**
A: Polynomial time. It refers to problems solvable in time $O(n^k)$.

**Q: Are all problems in P also in NP?**
A: Yes. If a problem can be solved in polynomial time, its solution can definitely be verified in polynomial time (by just re-solving it). Thus, $P \subseteq NP$.

**Q: Give an example of an algorithm that is NOT in P.**
A: An algorithm that generates all subsets of a set (Power Set) runs in $O(2^n)$, which is exponential, not polynomial.
