## Summary
**Commenting** is the primary way to communicate on GitHub. In AI development, comments are used for code review, discussing experimental results, and coordinating tasks.

## Detailed Explanation
### **Effective AI Commenting**
- **Review Comments**: Specific feedback on lines of code in a PR. "The learning rate here seems too high for this optimizer."
- **Issue Comments**: Discussing the root cause of a bug or clarifying a feature request.
- **Markdown Support**: Use code blocks (` ` `python) for snippets, LaTeX for math formulas ( = mx + b$), and tables for benchmarking.

### **Threads and Suggestions**
- **Threads**: Use "Reply" to keep related discussions grouped.
- **Suggestions**: Use the "Insert a suggestion" feature in PRs to provide the exact code fix, which the author can apply with a single click.

## Interview Questions
**Q: What is a "Code Suggestion" on GitHub and how does it speed up PR reviews?**
**A:** A code suggestion allows a reviewer to provide the exact code change in a comment. The PR author can then click "Commit suggestion" to apply it directly, eliminating the need to manually copy-paste or switch back to their editor.

**Q: How do you use Markdown to make your AI comments more readable?**
**A:** Use headers for structure, bold text for emphasis, bullet points for lists, and **fenced code blocks** with language syntax highlighting for code snippets.
